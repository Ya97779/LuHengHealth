## **1、帧格式**

### **1.1 写入 帧格式**

|     |     |     |
| --- | --- | --- |
| **字段** | **长度(字节)** | **说明** |
| 帧头  | 2   | 0xAA 0x55 |
| 数据长度 | 1   | N，表示后续数据区的字节数 |
| CMD 码 | 1   | 根据不同指令填写，例如 0x11、0x21、0x30 |
| 数据区 | N   | 可变长度，N 由数据长度字段指定；无数据时长度为 0 |
| 校验和 | 1   | 帧头到数据区所有字节的累加和，取低 8 位 |
| 帧尾  | 2   | 0x55 0xAA |

完整格式：AA 55 LEN CMD DATA\[LEN\] CHECK 55 AA

### **1.2 返回帧格式**

|     |     |     |
| --- | --- | --- |
| **字段** | **长度(字节)** | **说明** |
| 帧头  | 2   | 0xAA 0x56 |
| 数据长度 | 1   | N，表示后续数据区的字节数 |
| CMD 码 | 1   | 根据设备返回类型填写，例如 0x01、0x04、0x7F、0x80 |
| 数据区 | N   | 可变长度，N 由数据长度字段指定；无数据时长度为 0 |
| 校验和 | 1   | 帧头到数据区所有字节的累加和，取低 8 位 |
| 帧尾  | 2   | 0x56 0xAA |

完整格式：AA 56 LEN CMD DATA\[LEN\] CHECK 56 AA

### **1.3 ACK 帧格式**

|     |     |     |
| --- | --- | --- |
| **字段** | **长度(字节)** | **说明** |
| 帧头  | 2   | 0xAA 0x57 |
| 数据长度 | 1   | 5，表示后续数据区的字节数 |
| CMD 码 | 1   | 固定 0x7F，表示 ACK 返回 |
| 数据区 | 5   | 原 CMD STATUS 00 00 00（STATUS：01 成功；02 失败） |
| 校验和 | 1   | 帧头到数据区所有字节的累加和，取低 8 位 |
| 帧尾  | 2   | 0x57 0xAA |

完整格式：AA 57 05 7F 原CMD STATUS 00 00 00 CHECK 57 AA

| 03  | SIZE | 固件大小为 0、超过允许范围，或临时存储空间不足。 |
| 04  | SEQ | 包序号不符合期望。 |
| 05  | CHECKSUM | 当前 64 字节 DATA 的 16 位累加和错误。 |
| 06  | FLASH_WRITE | 写 Flash/DataFlash 失败。 |
| 07  | FLASH_VERIFY | 写入后读回校验失败。 |
| 08  | ERASE | 擦除失败。 |
| 09  | IMAGE_CHECKSUM | 结束帧中的固件总长度/总校验和与接收记录不一致。 |
